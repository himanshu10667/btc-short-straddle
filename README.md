# BTC Options Short Straddle

An algorithmic BTC options trading strategy developed using
Python, NautilusTrader, and the Bybit exchange.

## Objective

Implement an ATM Short Straddle by selling one Call option
and one Put option with the same strike and expiry.

## Implementation Levels

### Level 1
- Bybit Testnet connectivity
- BTC options market data subscription
- ATM strike selection
- Call and Put contract selection
- Automated Sell order submission
- Order and position monitoring

### Level 2
- 1% Stop-Loss
- 2% Take-Profit
- Combined premium monitoring
- Automated position closure

## Technology Stack

- Python 3.14
- NautilusTrader 2.x
- Bybit API
- uv
- Git
